# Aeolus Club Induction Tasks

## Candidate Details

- **Name:** Param
- **BITS ID:** 2026A8PS1050H
- **Subdivision:** Avionics

## Project

This repository contains the design of an autonomous search-and-rescue
quadcopter intended to locate Odysseus over the ocean.

## Design Constraints

- Maximum all-up weight: 2.5 kg
- Frame and propeller class: 10 inch
- Flight controller: Pixhawk 6C Mini
- Required endurance: More than 12 minutes
- Mission: Autonomous ocean search and rescue

## Tasks

1. [Autonomous Architecture](Task_1_Autonomous_Architecture/)
2. [Communication Architecture](Task_2_Communication_Architecture/)
3. [Propulsion System](Task_3_Propulsion_System/)
